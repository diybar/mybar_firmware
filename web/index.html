How to flash

Four steps, one cable

1

Connect the board

Use a USB data cable. Charge-only cables will not show a port. Close the Arduino IDE or any serial monitor.

2

Click Install

Pick the board's port in the chooser. It is usually named CP2102, CH340 or USB Serial.

3

Choose erase or keep

New or unknown board: Erase device. Board already running MyBar: keep existing data to preserve its settings.

4

Done

Wait for Installation complete. The board reboots and shows up in the MyBar app over Bluetooth.

Troubleshooting

No port appears in the chooser
  • Try another cable and a USB port directly on the computer, not a hub.
  • On Windows, install the driver for your board's USB chip: CP210x or CH340.
Stuck on "Connecting" or "Failed to initialize"
  • Hold the BOOT (IO0) button on the board while clicking Install, release once flashing starts.
  • Some boards also need a tap on EN/RESET while holding BOOT.
"Failed to open serial port"

Another program owns the port. Close the Arduino IDE, PlatformIO, serial monitors and any MyBar desktop tools, then try again.

Board does not show up in the app afterwards

Power-cycle the board. Open Logs & Console in the install dialog to confirm it boots. If it reboots in a loop, run Erase device and install once more.

Already on firmware 1.96 or newer?

You do not need a cable. The MyBar app updates the board over Bluetooth. This page is for first installs, boards older than 1.96, and recovering a board that no longer boots.
