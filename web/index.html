MyBar Web Flasher

Install the MyBar firmware on the ESP32 controller board from your browser

No Arduino IDE, no drivers to hunt for. Plug the board in, click install, done.

Your browser cannot talk to serial ports. Use Chrome or Edge on a desktop computer. This page must be opened over HTTPS to access serial ports.

How to flash

  1. Open this page in Chrome or Edge on Windows, macOS or Linux. Safari and Firefox do not support Web Serial.
  2. Connect the ESP32 board to the computer with a USB data cable. Some cables are charge only and will not show up.
  3. Click Install MyBar firmware and pick the board's serial port (usually CP2102, CH340 or USB Serial).
  4. On a brand new or unknown board choose Erase device when asked. On a board that already runs MyBar you can keep the existing data.
  5. Wait for Installation complete. The board reboots by itself and starts advertising over Bluetooth as usual.
Board not detected or stuck on "Connecting"?
  • Hold the BOOT (IO0) button on the board while the flasher connects, then release it.
  • Close the Arduino IDE, serial monitors or the MyBar app on this computer. Only one program can own the port.
  • On Windows, if no port appears, install the CP210x or CH340 driver for your board.
  • Try another USB port or cable, and avoid USB hubs.

Already running MyBar 1.96 or newer?

You do not need a cable. The MyBar app can push new firmware over Bluetooth. This page is for first installs, for boards older than 1.96, and for recovering a board that no longer boots.
